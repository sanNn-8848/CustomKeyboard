# MeroType - Quick Start (30 Seconds)

## TL;DR - Super Fast Install

### 1. Download
https://github.com/sanNn-8848/CustomKeyboard/releases

Click **"MeroType.apk"** > **Download**

### 2. Install
- Open **Downloads** > **MeroType.apk** > **Install**
- If error about "Unknown apps":
  - Settings > Apps > Special app access > Install unknown apps > Enable for Files

### 3. Enable
- Settings > Languages & input > Virtual keyboard
- Select **"MeroType Keyboard"**

### 4. Use
- Open any text app (Messages, WhatsApp, Email, etc.)
- Tap keyboard area
- **Start typing Roman Nepali!**

## Troubleshooting

**Can't install?**
- Enable "Install unknown apps" in Settings

**Keyboard doesn't appear?**
- Open Settings > Languages & input
- Make sure "MeroType" is enabled
- Select it as default keyboard

**No suggestions?**
- Open Settings
- Search for "MeroType"
- Enable "Show suggestions"
