# MeroType Installation Guide

## For End Users

### Prerequisites
- Android 5.0 or higher
- ~45 MB free storage
- Internet (only for download, keyboard works offline)

---

## Installation Steps

### Step 1: Download APK

**From GitHub Releases (Recommended)**
1. Go to: https://github.com/sanNn-8848/CustomKeyboard/releases
2. Find latest "MeroType" release
3. Click "MeroType.apk" to download

---

### Step 2: Allow Unknown Apps

Before installing APK, allow installation from unknown sources:

**Android 11+:**
1. Open Settings
2. Go to Apps > Special app access > Install unknown apps
3. Find "Files" app (or Chrome/Firefox if you downloaded there)
4. Toggle "Allow from this source" ON

**Android 8-10:**
1. Open Settings
2. Go to Security > Unknown sources
3. Toggle ON

**Android 5-7:**
1. Open Settings
2. Go to Security > Unknown sources
3. Toggle ON

---

### Step 3: Install APK

1. Open File Manager
2. Go to Downloads folder
3. Find "MeroType.apk"
4. Tap on it
5. Tap "Install"
6. Wait for installation (takes 10-30 seconds)
7. Tap "Done"

---

### Step 4: Enable Keyboard

1. Open Settings
2. Go to System > Languages & input
3. Tap Virtual keyboard
4. Select "MeroType Keyboard"
5. Toggle "Enable" or "Use as default"

---

### Step 5: Start Using!

1. Open any text app (Messages, WhatsApp, Email, Notes, etc.)
2. Tap on text field
3. Keyboard will appear
4. Start typing in Roman Nepali!

---

## Usage Tips

### Typing Roman Nepali
```
Type: "ke"
Suggestions appear: [ke] [kaho] [kasto]
Tap a suggestion or continue typing

Type: "namaste"
Suggestions: [namaste] [namaskaar] [namaskar]
Tap to select
```

### Special Keys
- **Shift Key** - Tap once for next letter uppercase
- **Double-tap Shift** - Caps lock (all uppercase)
- **Long-press keys** - Alternative characters
- **Backspace** - Delete last character
- **Space** - Add space between words

## Troubleshooting

**Can't install?**
- Allow "Install unknown apps" in Settings

**Keyboard doesn't show?**
- Enable it in Settings > Languages & input

**Suggestions not showing?**
- Enable "Show suggestions" in MeroType settings

**Uninstall**
1. Open Settings > Apps
2. Search "MeroType"
3. Tap > Uninstall
4. Confirm
