# MeroType Changelog

## [1.0.0] - 2026-09-06 (Initial Release)

### Added

#### Core Features
- Roman Nepali keyboard (QWERTY layout)
- 50,000+ word suggestions
- Smart context-aware predictions
- Offline-first (works without internet)
- User learning (learns from your typing)
- 100% privacy (local data only)
- No sign-up required
- Material Design 3 UI
- Light/Dark theme support

#### Keyboard Features
- Double-tap Shift for CAPS LOCK
- Long-press for alternative characters
- Backspace with repeat
- Space & Enter keys
- Auto-capitalization after period/newline
- Double-space period
- Key preview popups

#### Suggestions & Autocorrect
- Trie data structure for fast prefix matching
- N-gram model for word pair prediction
- Real-time autocorrect
- Next-word prediction

#### Emoji & Symbols
- Emoji keyboard with 250+ emojis
- Symbol keyboard
- Kaomoji support

#### Text Editing
- Cursor control (swipe on space bar)
- Text selection mode
- Copy/Paste/Cut toolbar
- Undo/Redo buttons

#### Settings & Themes
- 5 built-in themes (Dark, Light, Nepali Flag, Ocean, Forest)
- Custom theme support
- Haptic feedback toggle
- Key sound toggle
- Number row option
- One-hand mode

#### Privacy
- Incognito mode
- Local-only data
- No tracking or analytics
- No internet permission required

### Performance
- App size: ~45 MB
- Dictionary: ~5-8 MB
- Suggestion latency: 5-15ms
- Memory usage: 25-35 MB peak

### Technical
- Built with Kotlin
- Android InputMethodService
- Trie data structure for fast prefix matching
- N-gram model for word pair prediction
- Material Design components
- 100% offline functionality

### Known Limitations
- Roman Nepali only (Devanagari coming v2.1)
- No voice input yet (planned v1.1)
